🎮 STORE GAMING

Plataforma de venta digital de productos gaming, recargas, gift cards y servicios digitales.

🚀 Tecnologías

- Next.js 14
- React 18
- TypeScript
- Supabase
- Vercel
- API REST

📦 Características

- Registro e inicio de sesión de usuarios.
- Sistema de perfiles y balances.
- Recargas y productos digitales.
- Gift Cards.
- Integración con proveedores externos.
- Sistema de pedidos.
- Panel de administración.
- Gestión de depósitos.
- Sistema de soporte.
- Notificaciones.
- API individual para usuarios.
- Configuración de cuenta.

🛠️ Instalación

Instalar dependencias:

npm install

Iniciar el servidor de desarrollo:

npm run dev

Crear compilación de producción:

npm run build

🔐 Variables de entorno

Crear un archivo ".env.local" en la raíz del proyecto y configurar las variables necesarias.

Consultar ".env.example" para conocer las variables requeridas.

Nunca publicar claves privadas, contraseñas ni tokens en GitHub.

🗄️ Base de datos

El proyecto utiliza Supabase para gestionar:

- Usuarios.
- Perfiles.
- Balances.
- Pedidos.
- Depósitos.
- Notificaciones.
- Configuración de cuentas.

🌐 Despliegue

El proyecto está preparado para desplegarse en Vercel.

Conectar el repositorio de GitHub con Vercel y configurar las variables de entorno correspondientes.
